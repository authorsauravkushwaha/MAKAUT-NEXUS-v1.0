# Security Policy

## Supported Versions

The table below shows which versions of MAKAUT-NEXUS are currently receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                 |

## Reporting a Vulnerability

If you discover a security vulnerability in MAKAUT-NEXUS, please report it responsibly by following these steps:

1. **Do not open a public GitHub issue** for security vulnerabilities. This helps prevent malicious actors from exploiting the issue before it is fixed.
2. Instead, report it privately by:
   - Using GitHub's [private vulnerability reporting](../../security/advisories/new) feature on this repository (preferred), or
   - Emailing the maintainer directly at: **[email protected]**
3. Include as much detail as possible in your report:
   - A description of the vulnerability
   - Steps to reproduce the issue
   - The potential impact
   - Any suggested fix, if you have one

## What to Expect

- You will receive an acknowledgment of your report within **3-5 business days**.
- We will investigate and validate the reported vulnerability.
- If confirmed, we will work on a fix and aim to release a patch as soon as possible, depending on severity.
- You will be kept informed of the progress and notified once the issue is resolved.
- Credit will be given to the reporter in the release notes, unless anonymity is requested.

## Scope

This policy applies to the code and configuration contained in this repository (MAKAUT-NEXUS-v1.0). It does not cover third-party dependencies, which should be reported to their respective maintainers.

## Thank You

We appreciate the efforts of security researchers and users who help keep this project and its users safe. Responsible disclosure is valued and taken seriously.
